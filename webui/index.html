Run a Batch

Types a script into the console of every port you choose — for example to log in and reboot, factory-reset, or upgrade many devices at once — and keeps a record of each device. Runs on this box using its own serial ports, so a port that someone else has open (exclusive access) will fail with that reason.

Script reference
login <user> <password>Log in. Skips itself if a prompt is already showing. Fails if the device rejects the login.
send <text>Type the text and press Enter. A bare send just presses Enter. Any line that isn't one of these keywords is treated as send.
send-raw <text>Type the text with no Enter. Escapes: \r \n \t \e \xNN (for example \x03 is Ctrl-C).
expect <text>Wait until the device prints this text (not case-sensitive). Fails after the timeout (30 s by default).
expect-regex <pattern> [timeout=N]Same, with a regular expression and an optional timeout in seconds.
wait <seconds>Pause.
set idle <ms> / set timeout <seconds>Change how long to let the device go quiet after a command (default 1500 ms) and the default expect timeout.

Reset to Factory Default

      
Wipes all serial ports, console users, admin accounts, and SSH/TFTP/web/syslog settings back to their original defaults. The default admin account (admin / letmein0!) is recreated, forcing a password change on next login. Network settings, the SSH host key, the TLS certificate, and session capture files are left untouched. The service restarts immediately afterward and every active session, including this one, is signed out. This cannot be undone.
