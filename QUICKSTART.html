Quick Start

Serial Killer Terminal Server

Flashed image to first SSH session, in six steps.

HardwareRaspberry Pi 3/4/5, Zero 2 W, or Pi 2 B v1.2
StoragemicroSD card, 8 GB or larger
SerialOne USB-serial adapter per device you'll console into
NetworkEthernet cable — no Wi-Fi is preconfigured

  1. Flash the image

    Open Raspberry Pi Imager, choose Use custom, and select terminalserver-pi.img.gz.

    Skip customization

    Don't use Imager's own "OS customization" (username/password/Wi-Fi) options — this image already provisions itself on first boot, and Imager's settings would conflict with that.

  2. Boot it

    Insert the card, connect Ethernet, power on. First boot takes a few minutes: it sets up the OS and installs Node.js with zero prompts — nothing to type at a keyboard, even with one attached.

  3. Log in to the admin UI

    Visit https://terminalserver.local:8443 (accept the self-signed certificate warning) and sign in with admin / letmein0!.

    First login

    You'll be required to set a new password immediately — enforced by the server itself, so there's no way to skip it.

  4. Add your first serial port

    Serial Ports tab → + Add Port → click Refresh and pick the device from the list (prefer a /dev/serial/by-id/… path if one's offered — it survives a reboot, a raw ttyUSB0 path might not) → set the baud rate to match your equipment → Save.

  5. Add your first user

    Users tab → + Add User → set a password and/or an SSH public key → optionally assign the port you just added as their default, so they land straight in it → Save.

  6. Connect

    From any machine on the network:

    ssh -p 2222 <username>@terminalserver.local

    Press Ctrl+] any time to detach back to the port picker (if one's enabled for that user).

That's the essentials.
